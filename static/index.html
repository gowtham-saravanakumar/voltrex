What is this, exactly?

This isn’t a wrapper around a big commercial model. It’s a small decoder-only transformer — attention blocks, an MLP, causal masking, the same pattern every language model uses — built from raw building blocks and trained from a blank slate on a small text corpus.

It won’t write you an essay. It will, with any luck, string together a plausible, grammatical sentence within its narrow training domain. That gap between what it is and what it sounds like it should be, is the whole point of a toy model: you can see the machinery.
